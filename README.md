<h1> GIS - Gulf Intervention Society App</h1>

<h2>Overview</h2>
<h2>⚠️ Note</h2>
<p>
This project was developed as part of a professional collaboration with a company (ICOM). 
As it involves client-owned/proprietary code, the source code is not publicly available in this repository. 
This README documents my personal contribution and role in the project.
</p>
<p>
GIS is an events and community mobile application built for the Gulf Intervention Society — an external association for cardiac catheterization. The app allows medical professionals to discover and join upcoming events/conferences, stay updated with the latest news about the society, and learn more about the organization. Built and shipped entirely by me, live on both the <strong>App Store</strong> and <strong>Google Play</strong>.
</p>

<h2>Features</h2>

<h3>🔐 Onboarding &amp; Auth</h3>
<ul>
  <li>Splash screen and onboarding flow for first-time users.</li>
  <li>Full authentication flow (sign up / login).</li>
</ul>

<h3>📅 Events</h3>
<ul>
  <li>Browse upcoming events/conferences hosted by the society.</li>
  <li>Join events directly from the app.</li>
</ul>

<h3>📰 News &amp; About</h3>
<ul>
  <li>Display the latest news and updates about the society.</li>
  <li>Dedicated section with information about the organization.</li>
</ul>

<h3>💬 Community &amp; Engagement</h3>
<ul>
  <li>Users can create and publish <strong>posts</strong>.</li>
  <li><strong>Like</strong> and <strong>comment</strong> on posts.</li>
  <li>Edit profile screen for managing personal info.</li>
</ul>

<h3>🔔 Notifications</h3>
<ul>
  <li>Push notifications to keep users updated on events and activity.</li>
</ul>

<h2>Tech Stack</h2>
<ul>
  <li><strong>Framework:</strong> Flutter (Dart)</li>
  <li><strong>Architecture:</strong> MVVM (Model-View-ViewModel)</li>
  <li><strong>Networking:</strong> Dio (REST API integration)</li>
  <li><strong>Backend:</strong> REST API</li>
  <li><strong>Notifications:</strong> Push/in-app notifications</li>
</ul>

<h2>Architecture</h2>
<p>
Built entirely using the <strong>MVVM</strong> architecture, separating Model (data), View (UI), and ViewModel (business logic) for a clean, maintainable, and scalable codebase. API communication handled through <strong>Dio</strong> across all features (events, news, posts, profile).
</p>

<h2>My Role</h2>
<p>
Solely responsible for building the entire application end-to-end — from onboarding, auth, and events, to the community/social features and profile management 
</p>

<h2>Status</h2>
<p>✅ Live on the App Store and Google Play.</p>
